# ValidaSenhaForte (Java)

Exercício prático de validação didática de senhas em Java via console.

## 📌 Funcionalidades
- **RF01 - Entrada contínua**: Lê a senha via console (`Scanner.nextLine()`) mantendo caracteres intactos e permitindo novas tentativas em caso de erro.
- **RF02 - Tamanho mínimo**: Valida se a senha possui ao menos 8 caracteres.
- **RF03 - Validação de dígito**: Checa se a senha contém ao menos um número de 0 a 9.

## 🛠️ Tecnologias
- Java (JDK 8+)
- Lógica estruturada: `Scanner`, `boolean`, `while`, `if/else`

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/LucasHtech/ValidaSenhaForte.git
```

2. Acesse a pasta:
```bash
cd ValidaSenhaForte
```

3. Compile e execute:
```bash
javac ValidaSenhaForte.java
java ValidaSenhaForte
```
